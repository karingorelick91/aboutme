# היי, אני קארין 👋

אני מורה לשפת הסימנים, יוצרת ומפתחת תכנים נגישים ללמידה.

## קצת עליי

אני מתמחה בהוראת שפת הסימנים הישראלית ובהנגשת השפה בצורה ברורה, מעשית וחווייתית.

הקמתי את **לב הסימן – סטודיו לשפה, איור וסיפור**, שבו אני משלבת בין שפת הסימנים, הוראה, יצירה, איור וסיפור.

אני אוהבת להפוך ידע מורכב לתוכן פשוט, נגיש ואנושי, ולבנות חומרי לימוד שאפשר באמת להשתמש בהם בחיי היומיום.

## מה אני עושה

- מלמדת שפת סימנים ישראלית
- בונה קורסים דיגיטליים ללמידה עצמית
- מפתחת תרגולים וחומרי הוראה
- יוצרת תכנים חזותיים ונגישים
- עובדת על רעיונות לספרי ילדים, איור וסיפור
- מתעניינת בנגישות, חינוך וטכנולוגיה

## פרויקט מרכזי
